# Contributing

Thanks for helping improve Incident Canvas.

## Development

1. Fork the repository and create a focused branch.
2. Run `corepack enable` and `pnpm install`.
3. Make the smallest coherent change.
4. Run `pnpm lint`, `pnpm test`, and `pnpm build`.
5. Open a pull request that explains the problem and how you verified the solution.

Please add or update tests when behavior changes. Keep imported incident data backward compatible, avoid new network calls, and preserve keyboard access and print output.

## Reporting problems

Use the issue templates for bugs and feature requests. Report security concerns privately as described in [SECURITY.md](SECURITY.md).
